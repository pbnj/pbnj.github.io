This site is **plain HTML and CSS**, served by
[GitHub Pages](https://pages.github.com). No framework, _no JavaScript_.

## Why

- Nothing to install or upgrade
- Loads instantly
- Works in `lynx`

> Simplicity is prerequisite for reliability. — Edsger W. Dijkstra

## Adding a post

1. Write the post in Markdown under `posts/`
2. Run the build script
3. Commit the Markdown and the generated HTML

```sh
$EDITOR posts/my-post.md
scripts/build-posts
```
