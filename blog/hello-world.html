This site is plain HTML and CSS, served by GitHub Pages. No build step, no framework, no JavaScript.

Why

  • Nothing to install or upgrade
  • Loads instantly
  • Works in lynx
Simplicity is prerequisite for reliability. — Edsger W. Dijkstra

Adding a post

  1. Copy the template
  2. Write the post
  3. Link it from the post list, home page, and feed
cp blog/_template.html blog/my-post.html
$EDITOR blog/my-post.html
